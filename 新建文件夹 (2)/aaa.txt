1. 项目概述
================================================================================

本项目是一款基于 HTML5 Canvas 的经典坦克大战网页小游戏，融合现代玩法，
采用纯前端单 HTML 文件实现（内嵌 CSS + JavaScript），无任何外部依赖。
玩家通过键盘操控己方坦克消灭敌方坦克，闯关升级，挑战更高分数。

5. 关键算法说明
================================================================================

--------------------
5.1 碰撞检测（AABB 轴对齐矩形相交）
--------------------

算法：判断两个矩形是否在 X 轴和 Y 轴同时存在重叠。

  function checkCollision(a, b) {
    return (a.x < b.x + b.width) &&
           (a.x + a.width > b.x) &&
           (a.y < b.y + b.height) &&
           (a.y + a.height > b.y);
  }

应用场景：
  a) 玩家/敌方坦克 移动前 先做「预位移矩形」vs 所有墙体 + 其他坦克，
     若有重叠则该方向不移动，仅更新 direction 朝向（用于发射）。
  b) 炮弹每帧都 vs 所有墙体 + 所有坦克（敌我分开），命中即触发逻辑。
  c) 由于墙是 16px 网格，可做空间哈希优化：只需检查炮弹所在网格
     及相邻 8 格的墙，而非遍历全部 ~676 块墙。

--------------------
5.2 敌方 AI 移动与射击策略
--------------------

【移动策略】
每辆敌方坦克维护 moveTimer（初始 60~120 帧随机）和 direction：
  Step 1: 每帧 moveTimer--，>0 则沿 direction 持续移动。
  Step 2: moveTimer == 0 OR 撞上墙/边界/其他坦克 → 重新选方向：
    - 概率 30%：计算到玩家的曼哈顿方向，选择最接近的方向
        Δx = player.x - enemy.x;  Δy = player.y - enemy.y
        if (|Δx| > |Δy|) → (Δx>0 ? RIGHT : LEFT)  else → (Δy>0 ? DOWN : UP)
    - 概率 70%：从 {UP, DOWN, LEFT, RIGHT} 中完全随机
  Step 3: 重置 moveTimer = 60 + Math.floor(Math.random() * 60)

【射击策略】
  Step 1: shootCooldown 每帧递减。
  Step 2: 当 shootCooldown == 0 时，计算「射击命中可行性」：
    - 先取 enemy 当前 direction 对应射线路径；
    - 判断玩家是否在该射线的「锥形范围」内（方向匹配 + 曼哈顿距离<300px）
    - 满足 → 立即发射；不满足 → 50% 概率仍然瞎射（模拟紧张射击感）
  Step 3: 发射后 shootCooldown = 对应类型 shootInterval（NORMAL:90 / FAST:70 / HEAVY:110）

--------------------
5.3 关卡生成与地图布局
--------------------

【关卡地图格式】
使用二维数组表示 26列 × 26行 的 16px 网格：
  0 = 空地   1 = 砖墙   2 = 钢墙   3 = 基地（老鹰）

通用地图规则（每关相同）：
  - 画布尺寸：26 * 16 = 416px × 416px
  - 玩家出生点固定：grid(8,24) 和 grid(16,24)，即像素 (128, 384) 和 (256, 384)
  - 基地位置固定：grid(12,24)~(13,25)，即 32×32 像素区域，周围围 1 层砖墙
  - 敌方出生点：3 个，分别在 grid(0,0)、grid(12,0)、grid(24,0)

【关卡变化策略】
  - 每关砖墙分布：使用「种子随机」保证同一关布局稳定
      function generateLevelMap(level) {
        let rng = seededRandom(level); // 以 level 为种子
        // 在 26x26 网格中随机填充 20%~30% 砖墙，避开出生点和基地走廊
        // 随 level 升高，钢墙占比从 2% 升至 8%
      }
  - 每关敌人数 = 5 + (level - 1)，上限 8
  - 敌人类型加权：
      Level 1: NORMAL 100%
      Level 2: NORMAL 70%  FAST 30%
      Level 3+: NORMAL 50%  FAST 30%  HEAVY 20%
      Level 5+: NORMAL 40%  FAST 35%  HEAVY 25%

【过关流程】
  消灭所有敌人 → 显示「LEVEL CLEAR」2 秒 → level++ → 重新加载地图
  → 重置 enemiesRemaining = 5 + (level-1)，上限 8 → 玩家满血复活（保留生命数）

--------------------
6.2 布局尺寸
--------------------

【画布尺寸】
  - 游戏主画布：416 × 416 像素（26×26 格 × 16px）
  - 顶部 HUD 条：416 × 48 像素，位于画布上方或叠加在画布顶部（推荐独立绘制）
  - 整体页面宽度建议：520 像素（左右各留 52px 留白 + 可能的侧边敌人数展示）
  - 整体页面高度建议：520 像素（顶部 HUD 48 + 画布 416 + 底部提示 56）

【元素尺寸】
  - 坦克：32 × 32 像素（占 2×2 网格）
  - 墙体基础单元：16 × 16 像素
  - 炮弹：6 × 6 像素（圆形或矩形）
  - 出生点指示：32 × 32 像素闪烁边框
  - 基地（老鹰）：32 × 32 像素

【HUD 排版（顶部 48px 高条）】
  左── 分数 SCORE: 000000（#00FF7F 数值）
  中── LEVEL 1（加粗居中）
  右── ♥ × 3  ｜  ENEMY: 00/05

--------------------
6.3 字体与文字规范
--------------------
  - 推荐字体：'Press Start 2P'（像素风），降级 'Courier New' → monospace
  - HUD 标签字号：12~14px，数值字号加粗
  - 游戏内提示（Game Over / Level Clear）：24px，居中，加粗，
    颜色 #FFD700，外带 2px #000 描边
  - 控制说明（底部）：11px，#888 灰色
  - 生命图标用实心红心 ♥（Unicode）或者用 CSS/drawImage 绘制像素心

--------------------
6.4 交互反馈规范
--------------------
  - 玩家发射：轻微白闪（坦克炮口高亮 2 帧）
  - 墙体被击中：砖墙 1/4 格粉碎动画；钢墙 2 帧白色高亮反馈
  - 坦克被击毁：15 帧爆炸扩散动画（从 20px 扩至 40px，透明度 1→0）
  - 玩家复活：前 120 帧（2 秒）坦克闪烁（每 6 帧亮/暗交替）
  - 过关：全屏淡金色遮罩 + 居中「LEVEL CLEAR」停留 2 秒
  - 失败：全屏暗红色遮罩 + 居中「GAME OVER」+ 最终分数 + 「按 Enter 重玩」

7.3 运行方式
--------------------
方式一（最简）：
  1) 双击打开 tank-battle.html
  2) 自动启动主菜单，按「Enter」进入第 1 关
  3) 浏览器若限制本地文件字体，使用 monospace 兜底即可

方式二（推荐，避免个别浏览器 file:// 限制）：
  1) 打开命令行，切到文件所在目录
  2) 执行：python -m http.server 8080  （或 npx serve 等）
  3) 浏览器访问 http://localhost:8080/tank-battle.html

7.5 调试与调参建议
--------------------
  - 可视化碰撞盒：在 render() 中加 if(DEBUG) ctx.strokeRect() 画矩形描边
  - FPS 显示：每 60 帧计算一次 1/Δt，叠加左上角
  - 难度调节：修改 EnemyTypes.*.speed / shootInterval 即可快速调难度
  - 无敌时间：player.invincibleFrames = 0 可关闭复活无敌用于测试炮弹


================================================================================
附录 A：常见坑位与规避建议
================================================================================

A1. 玩家穿墙：务必在「移动前」先复制一份坐标移动后做碰撞检测，
    碰撞则不写入新坐标（只写新 direction 用于发射方向）。

A2. 坦克卡墙边缘：使用 4 点碰撞或先 X 轴再 Y 轴分轴移动判定，
    避免同时移动 XY 导致卡角。

A3. 敌方扎堆堵出生点：生成新坦克前先检测三个出生点是否有坦克/墙体占用，
    若占满则等待 30 帧再试。

A4. 基地误销毁：基地墙体设 type=BASE，渲染时画一个老鹰图标，
    碰撞逻辑中 BASE 被命中直接 GAME_OVER，给玩家强烈反馈。

A5. 帧率不稳：使用时间步长 Δt（秒/帧）做位移乘法，
    而非依赖固定 60fps，避免性能差的电脑出现敌人变慢。

A6. 输入丢键：用 keydown 置 true，keyup 置 false 的布尔表，
    不要用 keypress（会有操作系统重复输入延迟）。
